# Локалізація квізу та спільна лексика

`data/learning.json` — єдине редаговане джерело для квізу та бота Spanish by Serhii. Записи мають `id`, `es`, `uk`, `en`; Групи base/A2/B1 зберігають початковий порядок і повтори; A1 очищено від дублів. `group_metadata.A1` додає приклади й уточнення лише для A1. Після розширення A1 активна група містить 622 одиниці. A2, B1 та базовий список не розширені. Підрахунок, перетини й мовні рішення: `A1_EXPANSION.md`.

`tools/build_learning.py` генерує A1/A2/B1 з чотирма різними варіантами кожною мовою, копію джерела до сусіднього `telegram_bot/data`, fingerprint і `DATA_AUDIT.md`. Не редагувати згенеровані файли вручну.

```sh
python tools/build_learning.py --bot-root ../telegram_bot
python tools/build_learning.py --bot-root ../telegram_bot --check
node --test tests/quiz.test.cjs
```

`locales.js` містить спільні ключі uk/en. Параметр `lang` приймає лише `uk`/`en`; інші значення та його відсутність означають uk. Іспанські питання зберігаються. Telegram sendData передає `{level, lang, answers: [{id, chosen}]}`; бот повторно обчислює правильність за своєю копією джерела та перевіряє Premium користувача, а не довіряє параметрам URL.

Під час майбутнього погодженого deploy спочатку оновити бот: він підтримує попередній український payload. Старий бот не підтримує новий формат квізу. Rollback виконувати у зворотному порядку: квіз, потім бот.

Докладні налаштування, обмеження перевірок і ручні сценарії: `../telegram_bot/LOCALIZATION.md`. Поточні зміни не опубліковані, живі інтеграції й платежі не запускалися.
